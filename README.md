## Bharat — Digital Portfolio

### Structure
- `/views` — EJS page templates (home, about, education, professional-knowledge, gallery-pictures, gallery-videos, blog, blog-detail, messages, signup, login)
- `/models` — MongoDB schemas (User, Blog, Message)
- `/routes` — Express route handlers (auth, blog, messages)
- `/public` — static assets (CSS, images)
- `app.js` — application entry point

### Reference Analysis
This portfolio was built after reviewing [Professor Saay Salim's portfolio](https://saaysalim.github.io/Salim-Saay/) as a structural reference.

### Features
- Multi-page portfolio (Home, About, Education, Professional Knowledge, Picture Gallery, Video Gallery)
- Blog with user authentication (signup/login)
- Instant messaging facility
